# What Are Some AWS Defaults When It Comes to VPCs?

Area: VPC (https://app.notion.com/p/VPC-4eb43e7701874e7d8f341873e495229f?pvs=21)
Reveal: No
Confidence: Confident
Answer: - Users have a default VPC.
- Users have a default subnet.
- Users have a default NACL.
- Users have a default routes table.
- Users have a default internet gateway.
