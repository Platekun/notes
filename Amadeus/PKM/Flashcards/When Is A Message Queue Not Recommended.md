# When Is A Message Queue Not Recommended?

Area: Systems Design (https://app.notion.com/p/Systems-Design-a6bc2656ba664b749fca2279aa67a6fc?pvs=21)
Reveal: No
Confidence: Not Confident
Answer: A message queue is not recommended:
- For real time communication.
- For broadcasting purposes (because the messages can only processed by one “process”).
