# "Are all DTLs block chains?” Prompt

> *No, not all distributed ledger technologies (DLTs) are blockchains. A blockchain is a specific type of DLT that uses a chain of blocks to store and manage data. Each block contains a timestamp and a link to the previous block, forming a chain of blocks that is secured using cryptography.

However, DLTs can be implemented using a variety of technologies, such as blockchain, hashgraph, and directed acyclic graphs (DAGs). While blockchains are a widely used and well-known type of DLT, they are not the only type of DLT that exists.

Hashgraphs, for example, are a type of DLT that uses a different approach to storing and managing data. Rather than using a chain of blocks, hashgraphs use a directed acyclic graph (DAG) structure to store data, with each node in the graph representing a transaction. Hashgraphs are known for their high performance and scalability, making them suitable for use in a variety of applications.

Overall, while blockchains are a well-known and widely used type of DLT, they are not the only type of DLT that exists. Other types of DLTs, such as hashgraphs, offer different approaches to storing and managing data and may be more suitable for certain applications.*
