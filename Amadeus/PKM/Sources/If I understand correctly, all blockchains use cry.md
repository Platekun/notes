# "If I understand correctly, all blockchains use cryptography but not all DLT use cryptography?” Prompt

> *Yes, that is correct. All blockchains use cryptography to secure the ledger and ensure the integrity of the data. However, not all distributed ledger technologies (DLTs) use cryptography.

Blockchains are a specific type of DLT that use a chain of blocks to store and manage data. Each block contains a timestamp and a link to the previous block, forming a chain of blocks that is secured using cryptography.

Cryptography is the practice of using mathematical algorithms and protocols to secure information and prevent unauthorized access. In a blockchain, cryptography is used to secure the ledger and ensure that transactions and other data are protected from tampering and fraud.

However, DLTs can be implemented using a variety of technologies, and not all DLTs rely on cryptography. For example, hashgraphs, which are a type of DLT, use a different approach called "virtual voting" to achieve consensus on the state of the ledger. In this approach, each node in the DLT "votes" on the order of the transactions, and the DLT reaches consensus based on the majority of votes.

Overall, while blockchains are a specific type of DLT that use cryptography to secure the ledger, not all DLTs rely on cryptography. Some DLTs use alternative methods to achieve the same goal.*
