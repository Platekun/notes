# "When you say transactions broadcasted, you mean transactions initiated between users using crypto wallets?” Prompt

> *Yes, that's correct. When a user wants to send some amount of cryptocurrency to another user, they will create a transaction using their cryptocurrency wallet. This transaction will specify the amount of cryptocurrency being sent, the address of the recipient, and any other necessary information

Once the transaction has been created, the user will broadcast it to the network. This involves sending the transaction to other nodes in the network, which will receive and validate the transaction

Miners, in particular, will collect these transactions and store them in the transaction pool (also known as the memory pool or mempool) until they are ready to be included in a block. The transaction pool is a holding area for transactions that have been broadcast to the network but have not yet been included in a block

It's worth noting that transactions are not necessarily broadcast directly from one user to another. Instead, they are typically broadcast to the network as a whole, and it is the responsibility of the miners to collect and validate the transactions and include them in blocks.*
