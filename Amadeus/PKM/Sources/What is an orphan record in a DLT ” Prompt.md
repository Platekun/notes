# "What is an orphan record in a DLT?” Prompt

> *In a distributed ledger technology (DLT), an orphan record is a record that is not connected to the main chain of blocks. In a blockchain, blocks are linked together in a chronological chain, with each block containing a timestamp and a link to the previous block. An orphan record is a record that is not connected to this chain and is not recognized as a valid part of the DLT.

Orphan records can occur in a DLT for several reasons. One common reason is that the record was created by a malicious actor who is attempting to manipulate the DLT. Orphan records can also occur when two different versions of the same DLT are being used by different parties and do not agree on the order of the blocks. In this case, one version may contain an orphan record that is not recognized by the other version.

Orphan records can be a problem because they can cause confusion and make it difficult to track the history of transactions in the DLT. To prevent orphan records from occurring, DLTs typically use consensus mechanisms to ensure that all participants agree on the order of the blocks and the validity of the records.*
