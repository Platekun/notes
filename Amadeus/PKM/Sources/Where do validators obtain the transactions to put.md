# "Where do validators obtain the transactions to put in a block in a pos protocol?” Prompt

> *In proof-of-stake (PoS) systems, validators (the equivalent of miners in proof-of-work (PoW) systems) typically obtain transactions to include in a block from the transaction pool or mempool. The mempool is a holding area for unconfirmed transactions that are waiting to be included in a block.

When a new transaction is broadcast to the network, it is added to the mempool, where it waits to be picked up by a validator and included in a block. The specific process for selecting transactions to include in a block may vary depending on the PoS system being used

In some PoS systems, validators are required to include a certain number of transactions in each block, regardless of the transaction fees offered by the sender. In other PoS systems, validators may prioritize transactions with higher fees when selecting which transactions to include in a block

It's worth noting that the concept of a mempool is not unique to PoS systems and can also be found in PoW systems and other types of blockchain networks. The mempool helps to ensure that the network can process transactions efficiently by providing a temporary storage area for unconfirmed transactions.*
