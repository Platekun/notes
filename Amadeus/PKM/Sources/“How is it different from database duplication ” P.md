# “How is it different from database duplication?” Prompt

> *Database duplication is the process of creating a copy of a database on the same server or on a different server. The goal of database duplication is to have a backup of the data in case the original data is lost or becomes unavailable.

Database replication is similar to database duplication in that it also involves creating a copy of a database, but it differs in that it involves copying data from a database on one server (the master) to one or more databases on other servers (the slaves). The goal of database replication is to have a backup of the data in case the original data is lost or becomes unavailable, as well as to distribute data across multiple servers so that it can be accessed by more users or applications.

In contrast to database replication, database duplication does not involve replicating updates or changes made to the original database to the copied database. Instead, the copied database is a static snapshot of the original database at a specific point in time.*
