# "How are transactions selected in that case?” Prompt

> *In a proof-of-work (PoW) protocol, miners typically select transactions to include in a block based on the fees that the sender has paid. Transactions with higher fees are given priority because they are more profitable for the miner to include

When a user creates a transaction, they can specify the fee they are willing to pay to have the transaction processed. This fee is paid to the miner who includes the transaction in a block and helps to cover the costs of mining, such as electricity and equipment expenses

Miners will typically select the transactions with the highest fees first, as these are the most profitable for the miner to include. If there are more transactions than can fit in a single block, the miner will prioritize the highest-fee transactions and leave the lower-fee transactions in the transaction pool to be included in a future block

In this way, the fee system helps to ensure that miners have an incentive to process and validate transactions, and it also helps to prevent the transaction pool from becoming congested with low-fee transactions that may take a long time to be included in a block.*
