# "Miners are looking to create blocks, and they will solve a challenge in order to do so. If they get it right they will take as many transactions from the pool and shove them inside, is this correct?” Prompt

> *Yes, that's correct. In a proof-of-work (PoW) protocol, miners are responsible for creating new blocks and adding them to the blockchain. To do this, they perform a computationally intensive task to find a solution to a mathematical problem.

Once a miner has found a solution, they can create a new block and broadcast it to the network. Other miners will then verify the solution and, if it is valid, add the block to their copy of the blockchain.

Before creating a new block, the miner will typically select transactions from the transaction pool to include in the block. The miner can choose which transactions to include and in which order to place them. Transactions are usually selected based on the fees that the sender has paid, with higher-fee transactions being given priority.

Once the miner has selected the transactions to include in the block, they will bundle them together with the block header and broadcast the resulting block to the network. Other miners will then verify the block and, if it is valid, add it to their copy of the blockchain.

This process allows miners to process and validate a large number of transactions in a single operation, rather than having to perform the mining process separately for each individual transaction. It also helps to ensure the security and integrity of the network by making it difficult for malicious actors to alter the blockchain.*
