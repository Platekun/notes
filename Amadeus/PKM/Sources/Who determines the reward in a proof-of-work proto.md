# "Who determines the reward in a proof-of-work protocol?” Prompt

> *In a proof-of-work (PoW) protocol, the reward for mining a block is typically determined by the protocol itself. In the case of Bitcoin, for example, the reward for mining a block is currently 6.25 BTC (subject to halving every 210,000 blocks).

This reward is set by the Bitcoin protocol and is not subject to change, except through a process called a hard fork, in which the protocol is updated to introduce new rules or features. Hard forks are relatively rare and are typically used to make major changes to the protocol.

In addition to the block reward, miners also receive any transaction fees that are associated with the transactions included in the block they have mined. These fees are paid by users who want to have their transactions included in the next block, and the amount of the fee is typically based on the size of the transaction and the current demand for block space.

Overall, the reward for mining a block in a PoW protocol is determined by a combination of the block reward set by the protocol and any transaction fees associated with the transactions included in the block.*
