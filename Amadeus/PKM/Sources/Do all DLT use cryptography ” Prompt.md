# "Do all DLT use cryptography?” Prompt

> *Distributed ledger technologies (DLTs) are systems that allow multiple parties to record and verify transactions without the need for a central authority. While most DLTs use cryptography to secure the ledger and ensure the integrity of the data, not all DLTs rely on cryptography.

Cryptography is the practice of using mathematical algorithms and protocols to secure information and prevent unauthorized access. It is used in DLTs to secure the ledger and ensure that transactions and other data are protected from tampering and fraud.

However, some DLTs use alternative methods to secure the ledger and ensure the integrity of the data. For example, hashgraphs, which are a type of DLT, use a different approach called "virtual voting" to achieve consensus on the state of the ledger. In this approach, each node in the DLT "votes" on the order of the transactions, and the DLT reaches consensus based on the majority of votes.

Overall, while most DLTs use cryptography to secure the ledger, there are some DLTs that use alternative methods to achieve the same goal.*
