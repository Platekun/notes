# What Is A Blockchain?

A blockchain is a type of [[What Is A DLT|distributed ledger technology]] that uses cryptography techniques to store a collection of records (also referred as [[What Is A Block|blocks]]) in a linked fashion.

The usage of blockchains popularized with the appearance of blockchains like [[What Is Bitcoin|Bitcoin]] and [[What Is Ethereum|Ethereum]]. Which made them be compared to a new type of payment network like [PayPal](https://www.paypal.com/us/home).

Blockchains usage can be seen in different areas such as: [[What Is Crypto|Crypto]], [[What Is A Smart Contract|Smart contracts]], financial services (exploring their innovation potential), games (with [[What Is Crypto|crypto]] and [NFTs](https://app.notion.com/p/a9c60131a71f4570a3679b9cf77c85b6?pvs=21)), the supply chain industry, domain name registars, among many others.
