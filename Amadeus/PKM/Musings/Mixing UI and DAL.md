# Mixing UI and DAL

Everything can be a component but not everything should be a component or live inside components. There is the data and there is its presentation, those are different concerns.

> *I know everything is supposed to be a component, but not everything Should be inside of a component. For decades, devs have put data access in a different layer (DAL) and UI in the presentation layer. React encourages mixing the 2 and it's just bad practice! There, I said it.*
