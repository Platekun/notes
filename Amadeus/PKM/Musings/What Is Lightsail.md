# What Is Lightsail?

The Lightsail service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to deploy and scale web applications with a similar experience to what providers like [Heroku](https://www.heroku.com) does/did.

Lightsail’s business model revolves around simplifying even more the management of [[What is EC2|EC2]] applications by offering different templates depending on the technology stack that is going to be used. The configuration for the [[Subnetworks|network]], [[Security Groups|security]], [[Amadeus/PKM/Musings/What Is ELB|load balancing]], [[What Is An Auto Scaling Group|scaling]] and [[Amadeus/PKM/Musings/What Is RDS|database]] is done via questions prompted by [[Amadeus/PKM/Musings/What Is AWS|AWS]].
