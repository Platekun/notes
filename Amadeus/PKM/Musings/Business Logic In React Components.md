# Business Logic In React Components

According to a React core team developer, the tool should be thought as a rendering layer, separate from the logic of the business.

> [*@slicknet](https://twitter.com/slicknet) [@yaypie](https://twitter.com/yaypie) In React apps, business logic resides outside the component. Components are only concerned with rendering.*
