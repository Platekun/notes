# What Is RDS?

The Relational Database (Also known as RDS) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create and configure [[Managed Databases|managed]] relational databases. It has support for multiple database engines like: MariaDB, MySQL, MSSQL, Oracle, And Amazon Aurora.

Since RDS is a service for [[Managed Databases|managed]] databases, it performs all the heavy lifting that involves [[Self-Hosted Databases|self-hosting a database]] under the hood.
