# What Is SNS?

The Simple Notification (Also known as SNS) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to [[Integration Services|integrate different applications]] by using a [[Amadeus/PKM/Musings/What Is Serverless|serverless]] [[What Is PubSub|pubsub]].

SNS has support for FIFO messaging and multiple types of subscribers like [[Amadeus/PKM/Musings/What Is Lambda|Lambda]], [[Amadeus/PKM/Musings/What Is SQS|SQS]], [[What Is An HTTP API|HTTP]], email, SMS, mobile notifications, etc.

<aside>
<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> In order to set up our notification systems we have to use the [[How To Access AWS Using The AWS Management Console|management console]], however if we need to use them we have to use the SNS [[How To Access AWS Using AWS SDK(s)|SDK]] which allow us to interact them.

</aside>
