# What Is A Crypto Wallet?

A cryptographic wallet (also known as crypto wallet), is a hardware device or computer program which is used to generate and store the [[How Is Access Represented In Crypto|cryptographic keys]] of a person as well as providing the ability to [[What Is Bookkeeping|receive and transfer]] [[What Is Crypto|cryptocyrrency]].

It is important to note that the crypto wallet is only a tool used to facilitate the use of a [[What Is Crypto|cryptocurrency]]'s [[What Is A Blockchain|blockchain]] and it does not "*hold*” any kind of transactional state. The crypto wallet perform multiple reads across the list [[What Is A Block|blocks]] of the [[What Is A Blockchain|blockchain]] to compute the balance of the person using the crypto wallet (This process takes into account the different "[[What Is An Address|*addresses*]]” a person may have associated).

Performing a transaction with a crypto wallet means broadcasting a [[What Is Bookkeeping|transaction]] to a blockchain where the [[What Is Distributed Consensus|leaderless consensus protocol]] will take place ([[What Is Proof-of-Work|PoW]] in [Bitcoin](https://app.notion.com/p/e9e9b6b74d27498a82c16d5ee1015880?pvs=21) and [[What Is Proof-of-Stake|PoS]] in [[What Is Ethereum|Ethereum]]).
