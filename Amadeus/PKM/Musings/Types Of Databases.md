# Types Of Databases

Multiple database engines exists and each one has a philosophy regarding how data should be shaped. There are engines that value a structured schema like SQL databases, and there are those who are not bounded by any schema like NoSQL databases.

Choosing the right database requires accurate knowledge on the workload requirements of the system.
