# What Is An HTTP API?

An HTTP API is an [[Amadeus/PKM/Musings/What Is An API|API]] that can be accessed using the [HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) protocol. The programs involved in this type of API are the client and the server: The client send [HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) requests to the server that hosts the API.

HTTP APIs are a broad category of [[Amadeus/PKM/Musings/What Is An API|APIs]] because they have different characteristics depending on how programmers design their architecture. Usually we can observe a relation between  the functionality the [[Amadeus/PKM/Musings/What Is An API|API]] exposes and how the [HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Overview) request is shaped.
