# What Is ECR?

The Elastic Container Registry (Also known as ECR) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to [[Container Images Repositories|create and manage]] [[Amadeus/PKM/Musings/What Are Containers|container]] images. It’s AWS’ own version of [Dockerhub](https://hub.docker.com) which is integrated with [[Amadeus/PKM/Musings/What Is IAM|IAM]].
