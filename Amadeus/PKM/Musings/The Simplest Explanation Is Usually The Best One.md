# The Simplest Explanation Is Usually The Best One

What [[Alexis Leskinen]] is using here is called the “*Occam's razor*”. It is the problem-solving principle that recommends searching for explanations constructed with the smallest possible set of elements. This is attributed to William of Ockham and it is usually paraphrased as “*The simplest explanation is usually the best one*”.

The ideas behind this sentence has heavily influenced software development
