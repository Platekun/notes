# Reasons For Custom Back Buttons

Using custom back buttons instead of the one provided by the browser usually happens because we wish more control over where we want to send the user. There is a tension between what we wish and how the browser works.

> *I think this applies to angular apps as well. Sometimes there is a need to implement a custom back button. E.g when you enter a certain flow, you want to control whether you can go back or not. But unfortunately you need to create your own library with history api. Simple example, when u go to a page 404, then move to another page, you don't want your back button or navigation back button to redirect you to the page 404, but rather the page before it.*
