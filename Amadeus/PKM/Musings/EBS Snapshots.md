# EBS Snapshots

[[Amadeus/PKM/Musings/What Is EBS|EBS]] snapshots are [[Amadeus/PKM/Musings/What Is AWS|AWS]]’ way of performing back ups of [[Amadeus/PKM/Musings/What Is EBS|EBS]] volumes. It is possible to:

- Restore an [[What is EC2|EC2]] instance previous state.
- Create multiple copies of an [[What is EC2|EC2]] instance using the same [[Amadeus/PKM/Musings/What Is EBS|EBS]] snapshot (Not limited by [[Availability Zones|availability zone]]).
