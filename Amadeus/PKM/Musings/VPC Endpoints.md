# VPC Endpoints

[[What Is A VPC|VPC]] endpoints are a feature offered by [[Amadeus/PKM/Musings/What Is AWS|AWS]] that allows communication between resources inside a private network and other [[Amadeus/PKM/Musings/What Is AWS|AWS]] services. They are an alternative to setting up an internet gateway (or NAT gateway in this case).

This feature works by using [[Amadeus/PKM/Musings/What Is AWS|AWS]] own network called “*Private Link*”.
