# RDS Network Security

In terms of security [[Amadeus/PKM/Musings/What Is RDS|RDS]] make use of [[Security Groups|security groups]] just like [[What is EC2|EC2]] instances do. In addition to that, [[Amadeus/PKM/Musings/What Is RDS|RDS]] instances are usually deployed inside [[Private Subnetwork|private subnets]] to undersired traffic.
