# Multi-Factor Authentication

Multi-Factor Authentication (also known as MFA) is an authentication method which requires [[Users|users]] to provide multiple verification factors to obtain access to a resource (usually their account). 

AWS provides the means to enable MFA in our root account and user accounts via:

- Virtual Devices (e.g Authy).
- Physical Devices:
    - Universal 2nd Factor Key.
    - Hardware Key FOB MFA Device.
    - Hardware Key FOB Device For AWS GovCloud.
