# What Is Vite?

Vite is build tool that for front-end development which consists of:

- A development server.
- A `build` command.

Vite assumes we are using modern browser features which is why they use `esnext` as compilation target.

The development server provides similar features to every development server including hot-module-reloading and code compilation.

Vite serves source code using native ESM modules.

Vite plays the role of the development server and the browser plays the role of a bundler on development mode.

The build command bundles our code using Rollup.
