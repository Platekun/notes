# Reserved Instances

- Standard
    - Model: Rent [[What is EC2|EC2]] instances for fixed period of time.
    - Billing: Payment is upfront usually.
    - Use case: When an instance is required to exist between 1 to 3 years.
    - Example: A database.
- **Convertible**
    - Inherits the characteristics of the [[Launch Types|Reserved type]].
    - Model: Rent [[What is EC2|EC2]] instances for a fixed period of time with the benefit of having the ability to convert the instance into a different instance type.
- **Scheduled**
    - Inherits the characteristics of the [[Launch Types|Reserved type]].
    - Model: Rent [[What is EC2|EC2]] instances for a fixed period of time while also defining specific time periods when the instance should be available.
