# Password Policies

[[Users]] are expected to use a strong password is used to protect [[Users|users]] and [[User Groups|groups]] from being compromised.

In [[Amadeus/PKM/Musings/What Is AWS|AWS]] we can set a password policy with a variety of options like:

- Password length.
- Special character usage.
- Password re-use.
- Force password renewal.
- Allow [[Amadeus/PKM/Musings/What Is IAM|users]] to change their passwords.
