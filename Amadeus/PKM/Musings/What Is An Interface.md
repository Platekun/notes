# What Is An Interface?

An “*interface*” refers to a point where a human and a computer interact. Interfaces provide us with a “*thing*” which can be interacted with in order to perform “*something*”. This “*thing*” is a set of code, and “*something*” is whatever functionality the program allow us to do.

## Graphical User Interfaces

In this type of interfaces a human interacts with a program using interactive elements like buttons and inputs.
