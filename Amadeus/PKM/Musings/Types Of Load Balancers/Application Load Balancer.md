# Application Load Balancer

An application load balancer provides routing targeted at application architectures including microservices and containers. However to start routing traffic, it needs to be attached “[[Listeners|*listeners*]]” with a set of “[[Listeners|*rules*]]”.

Application load balancers can use security groups in order to protect the resources just like it is possible to do with a single resource.
