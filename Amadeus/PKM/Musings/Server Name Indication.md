# Server Name Indication

Server name indication (Also known as SNI) is an extension of the [[SSL And TSL|TSL]] protocol, where a client specifies which hostname it is attempting to connect at the beggining of the process. This results in a server presenting multiple certificates under the same [[IP Addresses|IP address]] and port.
