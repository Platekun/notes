# What Is A Smart Contract?

A smart contract is a computer program that is intended to execute the terms of a contract, an agreement with a set of conditions. They are intended to be self-executed once all the conditions are met. Similar to what a traditional contract does, their objective is to satisfy agreed contractual conditions.

The terms of a smart contract are represented as source code written in a programming language. Their logic can be perceived as very script-like since it is mainly used for [[What Is Bookkeeping|transaction-like operations]].

The usage of smart contracts popularized with the appearance of blockchains like [[What Is Ethereum|Ethereum]] however they are not exclusive to [[What Is A Blockchain|blockchains]]. 

They promise to mitigate some problems like malicious and accidental exceptions, untrusted intermediaries, arbitration agreements, enforcement costs among other problems faced by traditional contracts.

Smart contracts are a fundamental piece for the [[What Is Ethereum|Ethereum]] [[What Is A Blockchain|blockchain]] and are key concept to [decentralized finances](https://app.notion.com/p/6c0fe6e19f0a47a1a0d218736c687175?pvs=21) since they allow [[What Is Bookkeeping|financial transactions]] to occur.
