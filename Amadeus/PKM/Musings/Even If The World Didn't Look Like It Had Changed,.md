# Even If The World Didn't Look Like It Had Changed, Time Is Still Passing

“*Even if the world didn't look like it had changed, time is still passing.*” that is the first thing that came to my mind when I was reading this scene where Takuru enters his old room for the first time in a long time.

> *My room hadn't changed at all since I'd left half a year ago.*

I*t still had the same shelves, the same desk, and the same bed.

Everything was as I remembered it.

(It's honestly amazing how little has changed.)

I figured it would either have been turned into a storage room, or be covered in dust.*
>
