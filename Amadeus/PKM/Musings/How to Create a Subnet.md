# How to Create a Subnet

To get started navigate to the [[What Is A VPC|VPC]] home page:

[](https://us-east-1.console.aws.amazon.com/vpc/home?region=us-east-1)

![1. Navigate to the service home page and tap on “[Subnets](https://app.notion.com/p/6373779446024553b12162a0bc14da4f?pvs=21)”.](How%20To%20Create%20An%20Internet%20Gateway/Untitled.png)

1. Navigate to the service home page and tap on “[Subnets](https://app.notion.com/p/6373779446024553b12162a0bc14da4f?pvs=21)”.

![2. Tap on “*Create subnet*”.](How%20to%20Create%20a%20Subnet/Untitled.png)

2. Tap on “*Create subnet*”.

![3. Select the [VPC](What%20Is%20A%20VPC.md) that will hold this subnet.](How%20to%20Create%20a%20Subnet/Untitled%201.png)

3. Select the [[What Is A VPC|VPC]] that will hold this subnet.

![4. Input the name of the subnet. Then select the availability zone and [IPv4](https://app.notion.com/p/7c4b2ebf59fc4ccb8ccac763765ae1f7?pvs=21) [CIDR](https://app.notion.com/p/7e0d2aaa891747d3bfca0a1a766731b0?pvs=21). Submit the form by tapping on “*Create subnet*”.](How%20to%20Create%20a%20Subnet/Untitled%202.png)

4. Input the name of the subnet. Then select the availability zone and [IPv4](https://app.notion.com/p/7c4b2ebf59fc4ccb8ccac763765ae1f7?pvs=21) [CIDR](https://app.notion.com/p/7e0d2aaa891747d3bfca0a1a766731b0?pvs=21). Submit the form by tapping on “*Create subnet*”.
