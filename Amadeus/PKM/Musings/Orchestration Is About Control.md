# Orchestration Is About Control

Orchestration in applications usually refers to controlling all the possible events that could and should happen in a system and the ways they could be triggered.

> *Think about routing. We can easily make an <a href="/somewhere">, but where does that "/somewhere" come from? What if the routes change? This is fragile.*
