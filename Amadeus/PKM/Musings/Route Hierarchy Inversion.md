# Route Hierarchy Inversion

The author for some reason mentions GraphQL so this thinking comes more to an API point of view however we can extrapolate this to Front-End terms if we think of a stack navigator.

This seems to be related to [‣](https://app.notion.com/p/47a56eeb55634968a46fc6f376a8c468?pvs=21).

> Inversion of hierarchy not generally supported
Example with music-related collections: the following routes should all be possible
`/artists/my-band/songs/awesome-song
/albums/some-album/songs/awesome-song
/songs/awesome-song/artist
/albums/some-album/artist`
