# Stand By Replicas

A standby replica is a special type of database instance that serves as a backup for the primary instance on a [[Amadeus/PKM/Musings/What Is Multi AZ|multi AZ setup]]. This types of replicas cannot be used for writes or [[Read Replicas|reads]].
