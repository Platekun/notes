# How To Create A Route Table

To get started navigate to the [[What Is A VPC|VPC]] home page:

[](https://us-east-1.console.aws.amazon.com/vpc/home?region=us-east-1)

![1. Navigate to the service home page and tap on “[Route tables](https://app.notion.com/p/5a4e55c99ae24304a3c6f239644cbf2f?pvs=21)”,](How%20To%20Create%20An%20Internet%20Gateway/Untitled.png)

1. Navigate to the service home page and tap on “[Route tables](https://app.notion.com/p/5a4e55c99ae24304a3c6f239644cbf2f?pvs=21)”,

![2. Tap on “Create route table”.](How%20To%20Create%20A%20Route%20Table/Untitled.png)

2. Tap on “Create route table”.

![3. Input the name of the rotue table and select the VPC it operates with. Submit the form by tapping on “Create route table”.](How%20To%20Create%20A%20Route%20Table/Untitled%201.png)
