# Children Components In React VS Ember

React sees children as data needs to build a tree structure for diffing while Ember sees children as callbacks that return a deterministic shape to be rendered.

Both are functional programming approaches.

> *Yeah I think this might be one of the main philosophical differences in the view layer between Ember and React, once you strip away a lot of incidental details.
React sees children as data, while Ember sees it as a callback. Both are perfectly valid FP approaches.*
