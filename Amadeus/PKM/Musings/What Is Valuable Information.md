# What Is Valuable Information?

This is something similar to what Tiago Forte tries to advocate about having a second brain. Without purpose we can become data hoarders, but with a goal it can become a tool.

> *[[Takuru Miyashiro]] **:** There was nothing so useless as information that was inside you, but that you couldn’t retrieve when you needed it.

[[Takuru Miyashiro]] **:** Information was only valuable if you could use it.*
