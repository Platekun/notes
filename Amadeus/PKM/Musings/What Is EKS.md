# What Is EKS?

The Elastic Kubernetes (Also known as EKS) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create and manage [[Amadeus/PKM/Musings/What Are Containers|containers]] clusters. EKS uses [Kubernetes](https://kubernetes.io) under the hood, and its goal is to create a consistent deployment experience.
