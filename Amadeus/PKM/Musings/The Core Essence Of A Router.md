# The Core Essence Of A Router

When striving for simplicity, it seems a good idea is to just have the router fetch some data the page needs before rendering anything, that is `pause -> render` .

> *You can attach async functions to routes and wait for backend data to load before you even try to render. This is fast enough in many cases and simplifies the rendering code a lot.*
