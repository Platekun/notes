# RDS Access Management

[[Amadeus/PKM/Musings/What Is RDS|RDS]] allow us to use [[Amadeus/PKM/Musings/What Is IAM|IAM]] policies to control who can manage the [[Amadeus/PKM/Musings/What Is RDS|RDS]] instance. In addition to that, we can configure different methods like using username and password or [[Amadeus/PKM/Musings/What Is IAM|IAM]] based authentication to access the RDS instances.
