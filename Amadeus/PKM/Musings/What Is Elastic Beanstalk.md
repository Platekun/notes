# What Is Elastic Beanstalk?

The Elastic Beanstalk service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to deploy and scale web applications.

Elastic Beanstalk’s business model revolves around helping in creating [[What is EC2|EC2]]-based applications. The configuration for the [[Subnetworks|network]], [[Security Groups|security]], [[Amadeus/PKM/Musings/What Is ELB|load balancing]], [[What Is An Auto Scaling Group|scaling]] and [[Amadeus/PKM/Musings/What Is RDS|database]] is done via questions prompted by [[Amadeus/PKM/Musings/What Is AWS|AWS]].
