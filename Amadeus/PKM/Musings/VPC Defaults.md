# VPC Defaults

New users will see that [[Amadeus/PKM/Musings/What Is AWS|AWS]] creates certain resources by default:

- A default [[What Is A VPC|VPC]].
- A default [[What Is A VPC|subnet]].
- A default [[Network Access Control List|network access control list]].
- A default main [[Route Tables|route table]].
- A default [[Internet Gateway|internet gateway]] attached to [[What Is A VPC|the default VPC]].
