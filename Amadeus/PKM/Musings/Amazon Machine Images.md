# Amazon Machine Images

An amazon machine image (also known as AMI) is a blueprint used to create [[What is EC2|EC2]] instances. They specify the operative system, software and configuration.

<aside>
<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> We can create our custom AMIs using the [EC2 Image Builder service](https://us-east-1.console.aws.amazon.com/imagebuilder/home?region=us-east-1#/).

</aside>

As consumers we have the following options:

- We can create our own AMI for our custom needs.
- We can purchase and use AMIs created by other customers.
- We can use a public AMI (provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]]) as described on [[Choosing An Amazon Machine Image]].
