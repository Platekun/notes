# Public Subnetwork

A public subnet has a connection to the internet gateway and therefore resources within the subnet can receive incomming requests.

<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> Resources residing in a public subnet are supposed to have a [[Public IP Addresses|public IP addresses]].
