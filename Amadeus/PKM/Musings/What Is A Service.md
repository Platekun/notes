# What Is A Service?

A service defines the minimum and maximum number of [[What Is A Task|tasks]] one [[Amadeus/PKM/Musings/What Is A Task Definition|task definition]] can run. They also determine where to place new [[What Is A Task|tasks]], and similarly which tasks should be terminated.

<aside>
<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> Services use the [[Amadeus/PKM/Musings/What Is A Task Definition|task definitions]] to understand the systems requirements needed.

</aside>
