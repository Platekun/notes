# Conditionals vs Hierarchical States

Too many conditionals can be a code smell which could indicate the need for more specific states inside a given State *S*.

> *One thing I've noticed from working with state machines is how often we reach for conditionals, if this, if that, when what we really need is hierarchy. We don't need guards, we need nested states.*
