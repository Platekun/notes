# What Is A DLT?

A distributed ledger technology (also known as DLT) is a type of [[What Is A Dristributed Database|distributed database]]. It is used to [[What Is Bookkeeping|store a collection of financial transactions]] similar to what a [[What Is A Ledger|ledger]] does.

As a [[What Is A Dristributed Database|distributed database]], a DLT shares the usage of:

- A network of computers (in different geographical locations) where the data is stored.
- A [[What Is Distributed Consensus|leaderless consensus protocol]] in order to [[What Is A Dristributed Database|keep its state in sync]].

DLT(s) has certain methods like cryptography or "*virtual voting*” that ensure the security and integrity of the records, this allows multiple parties to access and update the records in a secure and transparent manner.

DTL(s) are classified depending on the data structures, [[What Is Distributed Consensus|consensus protocols]] and permissions they use.
