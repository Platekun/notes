# What Is ElastiCache?

The Elastic Cache (Also known as ElastiCache) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create and configure [[Managed Databases|managed]] in-memory databases. It has support for Redis and Memcached.

Since Elastic Cache is a service for [[Managed Databases|managed]] databases, it performs all the heavy lifting that involves [[Self-Hosted Databases|self-hosting a database]] under the hood.
