# Vertical Scalability

Refers to increasing (or improving) the specifications of a machine usually without the need of changing source code. Vertical scaled systems are share these characteristics:

- The system has a high consistency because all data is in one place.
- The system can suffer from downtimes when performing hardware upgrades.
- The system becomes a single point of failure.
- The system can only be updgraded to a degree because there are physical limits to how much a machine can be spec-increased.
- **Use case**: Non distributed systems.
- **Example**: Databases.
