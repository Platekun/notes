# Horizontal Scalability

Refers to increasing the number of machines that conform your system. Horizontally scaled systems share these characteristics:

- The system has a high [[Availability|availability]] because all data is in one place.
- The system downtime can be reduced if working with a load balancer.
- The system is resilient to outages, capacity can be [[What Is Cloud Computing|increased on demand]].
- The system can be upgraded well enough as long as we have the money to pay for capacity.
- **Use case**: Distributed systems.
- **Example**: Web applications.
