# Key Pairs

A key pair is a set of security credentials used to prove someone’s identity. The pair consists of a public and a private key. [[Amadeus/PKM/Musings/What Is AWS|AWS]] stores the public one while developers are responsible for storing the private somewhere safe.

The private key of the pair is used to connect to an instance using SSH.
