# What Is AppRunner?

The AppRunner service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to deploy containerized web applications and [[What Is An HTTP API|APIs]].

App Runner’s business model revolves around helping in deploying [[Amadeus/PKM/Musings/What Is ECS|ECS]] + [[Amadeus/PKM/Musings/What Is Fargate|Fargate]]-based applications.
