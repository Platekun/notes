# How To Create An Internet Gateway

To get started navigate to the [[What Is A VPC|VPC]] home page:

[](https://us-east-1.console.aws.amazon.com/vpc/home?region=us-east-1)

![1. Navigate to the service home page and tap on “[Internet gateways](https://app.notion.com/p/fb72787fcdfd4630a2643fa75ad6a519?pvs=21)”,](How%20To%20Create%20An%20Internet%20Gateway/Untitled.png)

1. Navigate to the service home page and tap on “[Internet gateways](https://app.notion.com/p/fb72787fcdfd4630a2643fa75ad6a519?pvs=21)”,

![2. Tap on “Create internet gateway”.](How%20To%20Create%20An%20Internet%20Gateway/Untitled%201.png)

2. Tap on “Create internet gateway”.

![3. Input the name tag and submit the form by tapping on “Create internet gateway”.](How%20To%20Create%20An%20Internet%20Gateway/Untitled%202.png)

3. Input the name tag and submit the form by tapping on “Create internet gateway”.
