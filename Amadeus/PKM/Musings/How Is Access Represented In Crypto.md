# How Is Access Represented In Crypto?

The proof that we have access of our cryptocurrencies within a [[What Is A Blockchain|blockchain]] is represented by a posession of a pair of cryptographic keys (a long string of letters and numbers).

To obtain our own cryptographic keys and start performing transactions within a blockchain like [[What Is Bitcoin|Bitcoin]] or [[What Is Ethereum|Ethereum]], we need to make use of a [[What Is A Crypto Wallet|crypto wallet]], which will generate a pair for us.

## Public Keys

A public key is a key that is used to identify an "*address*” or "*account*” within the blockchain. 

These types of keys can be shared with other people without security concerns as they the equivalent to a bank account.

They are needed in order to perform a validation step in a [[What Is Bookkeeping|transaction]] within a [[What Is A Blockchain|blockchain]] (recipient side).

## Private Keys

A private key is a key that gives access to the associated "*address*” or "*account*”.

These types of keys should not be shared with other people since they are the equivalent of a password to a bank account.

They are needed in order to perform a signing step in a [[What Is Bookkeeping|transaction]] within a [[What Is A Blockchain|blockchain]] (sender side).

To receive a transaction, access to the private key is not need. A transaction can be a purely one-sided operation of sending the cryptocurrency with the public key.
