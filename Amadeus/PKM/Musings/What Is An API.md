# What Is An API?

An Application Programming Interface (also known as API) is a special type of [[Amadeus/PKM/Musings/What Is An Interface|interface]] whose purpose is to allow the interaction between two programs without humans involved. In order to accomplish this, a set of rules and formats have to be followed.

APIs are made up of code, and they provide to programmers different components like objects, functions, variables that provide a functionality. Using one of the parts provided by the API is referred as “*to call an API*”, hence the expression “*calling an API*”.

There are different types of APIs:

- [[Amadeus/PKM/Musings/What Is A Software API|Software APIs]].
- [[What Is An HTTP API|HTTP APIs]].
