# We Have Gone Full Circle From PHP To React

PHP was a language designed for ease of use and started as templating language. With time, developers noticed that having business logic inside templates felt bad as an architecture and started separating those into different languages. It feels history repeats itself now seeing React encouraging to mix business logic with markup.

Just because you can mix them does not mean you should.

> *PHP started out as a templating language. As it grew to a full language, templating languages had to be written to use with PHP to stop people mixing business logic with markup, which is a really bad idea.
People are now making the same mistakes with React.*
