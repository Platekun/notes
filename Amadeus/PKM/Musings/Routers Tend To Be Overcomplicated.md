# Routers Tend To Be Overcomplicated

Routers sometimes tend to overcomplicate things. Some developers only look for a thin abstraction to map components to URL(s).

> *Most routers are over complicated. We just want basic navigation on top of the history API, mapping routes to components and stuff. Router stuff should stop trying to be so fancy and just be simple*
