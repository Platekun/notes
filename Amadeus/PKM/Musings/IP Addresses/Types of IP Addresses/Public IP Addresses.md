# Public IP Addresses

These type of [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]] are used as the primary way to communicate outside the network (Internet). Public [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]] are generated by the ISP (Internet Service Provider) and there is a cost associated to them because there is a limited number of them in the world.
