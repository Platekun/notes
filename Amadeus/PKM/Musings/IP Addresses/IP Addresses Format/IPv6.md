# IPv6

The successor to IPv4 was IPv6, created in 1998. It was designed to solve the problems presented by IPv4, allowing an even greater number of [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]].

This version allows every device on the planet to have its own [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]] however the migration has been slow due to significant costs of upgrade.

An IPv6 address consists of a numerical label with a `y:y:y:y:y:y:y:y` format, where `y` are called “*segments*” and can be hexadecimal values between `0` to `FFFF`. Normal IPv6 addresses have 8 segments.

```
2001:db8:3333:4444:5555:6666:7777:8888
2001:db8:3333:4444:CCCC:DDDD:EEEE:FFFF
```
