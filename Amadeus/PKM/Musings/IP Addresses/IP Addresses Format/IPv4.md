# IPv4

The original internet protocol is IPv4, created around 1980. This protocol version allows for a theoretical maximum of `2^32` of [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]] however the number is far less due to inefficiencies in the way blocks of numbers are handled by networks.

An IPv4 address consists a string of numbers separated by periods consisting in four numbers from `0` to `255`, an octet (8) of [[What Are Bits|What Are Bits?]].

```
192.158.1.38
192.255.72.38
255.0.40.1
172.16.254.1
69.89.31.226
```
