# Stupidity and Friendly APIs

React’s API or docs are friendly enough so people do not feel afraid of using the tool or encountering an error. Since people like not feeling stupid then it reciprocates on its popularity.

Another factor can be that React’s API is small compared to other frameworks with their opinions.

> *Just an observation but...
When stuck in other tools: "This is stupid, what were they thinking when they made it work this way?"
When stuck in React: "I'm sure this is the best API, I'm just not smart enough for it yet."
How they do this to me I'll never truly understand*
