# Instance Types

[[Amadeus/PKM/Musings/What Is AWS|AWS]] provides a catalog of difference [[What is EC2|EC2]] instances optimized for different use cases. They are usually identified by their particular way of categorization:

```
m5.2xlarge
---
"m" represents the instance class.
"5" represents the generation.
"2xlarge" represents the size within the class
```
