# What Is Amplify?

The Amplify service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to build full-stack applications with [[What is EC2|AWS]] services. Amplify is both a framework for developing applications and a platform which can be used to design and host them as well.

Amplify’s business model revolves around being a wrapper around multiple [[Amadeus/PKM/Musings/What Is AWS|AWS]] services which can be tiresome to use independently and figuring out how to integrate them.

Development with Amplify is expected to be done using its CLI and SDK.
