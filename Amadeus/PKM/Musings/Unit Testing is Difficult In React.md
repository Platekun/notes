# Unit Testing is Difficult In React

The React movement always displayed the notion of reinventing all practices to their own way and adjusting principles so they are coupled to the library. [‣](https://app.notion.com/p/a3b605c8ca094a65b38be20daf0293ff?pvs=21) shares this sentiment as well.

Mixing concerns produces code that is difficult to unit test and we need to rely on integration test.

> R*eact encourages app logic inside UI code, making app logic units difficult or impossible to exercise. With no accessible logic, React devs redefined or rejected "unit test". Then they rejected the testing pyramid based on that. But it's not about testing; it's about React.*
