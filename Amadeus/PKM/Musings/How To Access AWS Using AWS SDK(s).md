# How To Access AWS Using AWS SDK(s)

AWS provides us with the software development kits (also known as SDKs) which let us write code that in the end send commands to use AWS services in a certain way. 

Using SDKs grant programatic access and allow us to have infrastructure as code (IaaS). This allows SDKs to be a great candidate for automating tasks.

To read the different SDKs provided by Amazon written in JavaScript visit:

**Getting started with Node AWS SDKs**

[Getting started in Node.js](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/getting-started-nodejs.html)

**Getting started with Browser AWS SDKs**

[Getting started in a browser script](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/getting-started-browser.html)

**Getting started with React Native SDKs**

[Getting started in React Native](https://docs.aws.amazon.com/sdk-for-javascript/v3/developer-guide/getting-started-react-native.html)
