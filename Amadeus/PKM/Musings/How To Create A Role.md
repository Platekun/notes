# How To Create A Role

To get started navigate to the [[Amadeus/PKM/Musings/What Is IAM|IAM]] home page:

[](https://us-east-1.console.aws.amazon.com/iamv2/home?region=us-east-1#/home)

![1. Navigate to the service home page and tap on “[*Roles*](https://app.notion.com/p/34c23f439abb4209a5e0e62df0ef5508?pvs=21)”.](How%20To%20Create%20A%20Role/Untitled.png)

1. Navigate to the service home page and tap on “[*Roles*](https://app.notion.com/p/34c23f439abb4209a5e0e62df0ef5508?pvs=21)”.

![2. Tap on ”Create role”.](How%20To%20Create%20A%20Role/Untitled%201.png)

2. Tap on ”Create role”.

![3. Depending on the use case we have to select the entity that will use the role and provide some extra information.](How%20To%20Create%20A%20Role/Untitled%202.png)

3. Depending on the use case we have to select the entity that will use the role and provide some extra information.

![3.B In case the entity type is an AWS service we can select it using the select.](How%20To%20Create%20A%20Role/Untitled%203.png)

3.B In case the entity type is an AWS service we can select it using the select.

![4. Select the [policies](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) that will be associated with this role.](How%20To%20Create%20A%20Role/Untitled%204.png)

4. Select the [policies](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) that will be associated with this role.

![5. Input the name of the role and description.](How%20To%20Create%20A%20Role/Untitled%205.png)

5. Input the name of the role and description.

![6. Preview. Then submit the form.](How%20To%20Create%20A%20Role/Untitled%206.png)

6. Preview. Then submit the form.
