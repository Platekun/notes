# What Is Serverless?

Serverless is a development model which allow us to build applications where we don’t need to provision, configure or pay for servers. Using this model the burden of worrying about the infrastructure or configuration is removed.

Serverless services are thought to solve a specific piece of work, this is called a “*Task*”. Tasks can be different depending on the serverless service. The pricing of serverless services only depend on the execution time of this task.

Serverless architectures are on-demand and event-driven, meaning they can connect tasks to an specific event triggers that originate from another service with almost automatic scaling, e.g in [[Amadeus/PKM/Musings/What Is AWS|AWS]]’ context we could execute some code given an image was uploaded to [[What Is S3|S3]].
