# React Still Needs A Good REST Solution

REST API(s) need a good solution in React land (or event Front-End to speak about). The community is trying to shove GraphQL on top of everything while in the real world, not many people are going to rebuild systems just for another new framework.

React Query and SWR are good starters but they require a lot of manual wiring at the moment.

> *The state of REST apis in React is sad. SWR is great, but requires a lot of manual wiring for deeply nested REST routes
It’s like GraphQL just made people give up on ever making REST in React nice, and now the majority of React users are dealing with shit

GraphQL is great, but only a small fraction of companies are using it at this point. Many of these APIs are 5, 10, 15 years old and have watched many JavaScript frameworks come and go. They aren’t going to rewrite them for React’s sake.*
