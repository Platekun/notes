# Simplifying Services

Due to the high complexity nature that [[Amadeus/PKM/Musings/What Is AWS|AWS]] displays, it can be troublesome to begginners to get started with using [[Amadeus/PKM/Musings/What Is AWS|AWS]]. This is the main reason why [[Amadeus/PKM/Musings/What Is AWS|AWS]] offers services that work on top of building block services like [[What is EC2|EC2]], [[Amadeus/PKM/Musings/What Is ECS|ECS]], [[Amadeus/PKM/Musings/What Is EKS|EKS]], etc. but which are easier to use for people without domain expertise.
