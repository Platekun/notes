# What Are Step Functions?

The Step Functions service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create and manage workflows of microservices visually.

Step Functions is marketed towards microservices orchestration. Users can create execution diagrams using a GUI, and each step in the diagram have its defined inputs, outputs and lambda source code.
