# Choosing A Database Strategy

When designing our system we usually end up with the need of running a database where we can store our data. The decision of selecting the correct database can be grouped in two factors:

- [[Types Of Databases|The type of database]].
- The hosting strategy, which can be either of these:
    - [[Self-Hosted Databases|Self-hosting a database]].
    - Using a [[Managed Databases|managed database]].
