# How To Create A User Group

To get started navigate to the [[Amadeus/PKM/Musings/What Is IAM|IAM]] home page:

[](https://us-east-1.console.aws.amazon.com/iamv2/home?region=us-east-1#/home)

![1. Navigate to the service home page and tap “[*Users*”](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21), then “[*User Groups*](https://app.notion.com/p/cb21fbef1b1b48669df1da70387b8041?pvs=21)”.](How%20To%20Create%20A%20User%20Group/Untitled.png)

1. Navigate to the service home page and tap “[*Users*”](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21), then “[*User Groups*](https://app.notion.com/p/cb21fbef1b1b48669df1da70387b8041?pvs=21)”.

![2. Tap on “*Create group*”.](How%20To%20Create%20A%20User%20Group/Untitled%201.png)

2. Tap on “*Create group*”.

![3. Input the group name, the members of the group and the [policies](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) for the group. Then submit the form.](How%20To%20Create%20A%20User%20Group/Untitled%202.png)

3. Input the group name, the members of the group and the [policies](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) for the group. Then submit the form.
