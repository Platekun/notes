# Elasticity

Elasticity is the ability to add or remove resources as needed quickly. It is used for short-term planning to meet spikes of traffic in short periods of time.

This characteristic of a system is found in [[What Is Cloud Computing|cloud-based systems]] which allows to automatically add or remove infrastructural resources based on certain criteria.
