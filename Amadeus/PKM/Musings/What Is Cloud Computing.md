# What Is Cloud Computing?

“*Cloud Computing*” is the on-demand delivery of IT resources over the internet, often with a pay-as-you-go pricing model and companies that work in this area are known as “*Cloud Computing Service Providers*” (CCSP).

As customers we can leverage the infrastructure owned by the CCSPs via services built on top of that infrastructure.

Common examples of cloud computing are:

- [[What is EC2|Renting servers]] to serve websites.
- [Renting file storage](https://app.notion.com/p/e17e554a2668496880fe192286a41877?pvs=21).

## Advantages

- [[Reliability]].
- Agility: We can generate and use cloud services within minutes.
- [[Elasticity]].
- [[Scalability]].
- The payment model is often “pay-as-you-go” which means we only pay for the resources we use, there is no cost generated by iddle resources.
- [[Availability]].

## Disadvantages

- We are trading fixed costs for variable expenses depending on our demand.
