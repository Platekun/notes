# How To Create A Budget

To get started navigate to the Billing Dashboard home page:

[](https://us-east-1.console.aws.amazon.com/billing/home?region=us-east-1#/)

## Creating A Budget

For first time users (and for experienced users as well) it is recommended to create a budget for our costs. Budgets allow us to trigger alarms when our current bill of the month surpasses a certain specified amount.

![1. Navigate to the service home page and tap on “*Budgets*”.](How%20To%20Create%20A%20Budget/Untitled.png)

1. Navigate to the service home page and tap on “*Budgets*”.

![2.  Choose the budget type and tap on “*Next*”.](How%20To%20Create%20A%20Budget/Untitled%201.png)

2.  Choose the budget type and tap on “*Next*”.

![3. Fill the fields with the specified amount of money we want for this budget and tap on “*Next*”.](How%20To%20Create%20A%20Budget/Untitled%202.png)

3. Fill the fields with the specified amount of money we want for this budget and tap on “*Next*”.

![4. As an optional step, set the [thresholds](https://app.notion.com/p/19ffc71a130b4807a5bd37a85194c840?pvs=21) and finish by tapping on “*Next*”.](How%20To%20Create%20A%20Budget/Untitled%203.png)

4. As an optional step, set the [thresholds](https://app.notion.com/p/19ffc71a130b4807a5bd37a85194c840?pvs=21) and finish by tapping on “*Next*”.
