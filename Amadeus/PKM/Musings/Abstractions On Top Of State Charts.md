# Abstractions On Top Of State Charts

State charts are the means to an end, not the end itself. Proof of this is that when using a framework like Ember, we can focus on application related problems rather than focusing on how to render things or how to optimize rendering. Ember is a collection of State charts with a thin API layer.

> [*@nullvoxpopuli](https://twitter.com/nullvoxpopuli) most of Ember is already many state machines. Ember is more then React/Vue in that it give you app level solutions instead of only focusing on view rendering. Where XState shine in ember are business logic and model-based testing.*
