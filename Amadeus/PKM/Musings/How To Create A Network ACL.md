# How To Create A Network ACL

To get started navigate to the [[What Is A VPC|VPC]] home page:

[](https://us-east-1.console.aws.amazon.com/vpc/home?region=us-east-1)

![1. Navigate to the service home page and tap on “[Network ACLs](https://app.notion.com/p/48be3affc1c3418089572b7dcb1907b9?pvs=21)”.](How%20To%20Create%20An%20Internet%20Gateway/Untitled.png)

1. Navigate to the service home page and tap on “[Network ACLs](https://app.notion.com/p/48be3affc1c3418089572b7dcb1907b9?pvs=21)”.

![2. Tap on “*Create network ACL*”.](How%20To%20Create%20A%20Network%20ACL/Untitled.png)

2. Tap on “*Create network ACL*”.

![3. Input the name of the [NACL](https://app.notion.com/p/48be3affc1c3418089572b7dcb1907b9?pvs=21) and select the [[What Is A VPC|VPC]] it operates with. Submit the form by tapping on “*Create network ACL*”.](How%20To%20Create%20A%20Network%20ACL/Untitled%201.png)

3. Input the name of the [NACL](https://app.notion.com/p/48be3affc1c3418089572b7dcb1907b9?pvs=21) and select the [[What Is A VPC|VPC]] it operates with. Submit the form by tapping on “*Create network ACL*”.
