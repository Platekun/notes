# Data VS State

State Charts let us describe: State, data, side-effects and events relationships. This approach is more fully-equipped to describe our applications than Redux or MobX which only describe data.

> *For me it’s data vs state. An app can only be in one “state” (different than normal react meaning) but manage lots of data between state transitions (events). Redux/mobx are just the data part. Xstate lets me describe state, data, effects, and their relationships through events.*
