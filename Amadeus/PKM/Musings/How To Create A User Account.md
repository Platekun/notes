# How To Create A User Account

To get started navigate to the [[Amadeus/PKM/Musings/What Is IAM|IAM]] home page:

[](https://us-east-1.console.aws.amazon.com/iamv2/home?region=us-east-1#/home)

![1. Navigate to the service home page and tap “[*Users*](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21)”.](How%20To%20Create%20A%20User%20Account/Untitled.png)

1. Navigate to the service home page and tap “[*Users*](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21)”.

![2. Tap on “Add [Users](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21)”.](How%20To%20Create%20A%20User%20Account/Untitled%201.png)

2. Tap on “Add [Users](https://app.notion.com/p/5c5f1924674747489a7ab86309f39b03?pvs=21)”.

![3. Fill the form. Input the username and the programmatic access.](How%20To%20Create%20A%20User%20Account/Untitled%202.png)

3. Fill the form. Input the username and the programmatic access.

![4. Input whether to add the new user to a group or attach an existing [policy](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) directly. ](How%20To%20Create%20A%20User%20Account/Untitled%203.png)

4. Input whether to add the new user to a group or attach an existing [policy](https://app.notion.com/p/4920c7bc48cf4041a4ba1c3bc7e482e0?pvs=21) directly. 

![6. Optionally set meta information via tags.](How%20To%20Create%20A%20User%20Account/Untitled%204.png)

6. Optionally set meta information via tags.

![7. Review the input data and submit the form.](How%20To%20Create%20A%20User%20Account/Untitled%205.png)

7. Review the input data and submit the form.
