# The Framing Problem

> *[[Hiyajo Maho]]: An AI needs to consider an endless number of attached conditions to know how to execute an order.

[[Hiyajo Maho]]: The vast majority of those conditions can probably be ignored, but the AI doesn't know which to ignore.

[[Hiyajo Maho]]: Which means it has to consider everything.

[[Hiyajo Maho]]: But “everything” is a finite set, isn't it?

[[Hiyajo Maho]]: If it has to examine an infinite number of conditions, it will never be able to pick up that box.

[[Hiyajo Maho]]: A human can easily frame which conditions need to be accounted for, but an AI can't.*
>
