# React Arguments

React tends to add their own nomenclature to their concepts even if they do not match entirely to the JavaScript specification. This is why we see “*arguments*” being called “*props*”. But for some reason developers want to move those concepts into other API(s) that have nothing to do with React.

> *It drives me crazy that React's original class-based implementation resulted in the JavaScript community renaming "arguments" to "props".
JavaScript properties exist. They're properties of an object. When you call a function you pass arguments. That's why people write `...args`.

What especially drives me crazy is watching people casually describe things that obviously are arguments as "props" in other APIs.*
