# Focus Instead Of Panicking

Panicking is usually the worst thing we can do in a moment of stress. Is there any way we can control that feeling? I think this has to do with how we focus our attention. Feels like when there is a problem that feels "*all over the place*” like a messy room, it usually helps focusing on just one thing, something that can be solved no matter how trivial it is.
