# Why The React Community Is Missing The Point Of Web Components

- React developers are too heavily invested in their library.
- The react bubble will eventually burst, sooner or later.
- Using web components does not mean not using React. You can use them together and have results that can increase your performance.
- Using raw web components can be cumbersome but there are libraries that already mitigate this problem like lit-html.
- “*React is tomorrow's MooTools*".
- Web Components are standard.
- The react community either does not accept standards, they say WebComponents are hard to work with or state that they can't do what react does.
- React has brought wonderful things like a functional approach to UI, one-way data flow patterns and popularized the component model but React is not the future.
- React has also brought cons like unnecessary and cumbersome tooling like babel and Webpack and the false statement that you can only do component-based development with react.
- The future tends to be on the side of open standards rather than implementations however implementations may be the way to standards.
