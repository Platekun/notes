# What Is EFS?

The Elastic File System (also known as EFS) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create a file system completely managed by [[Amadeus/PKM/Musings/What Is AWS|AWS]].

As the “[[Elasticity|*elastic*]]” part of the name implies, this file system can grow or shrink automatically as files are added or removed.

EFS is designed to make its content [[Availability|highly available]] and durable. Data is stored redundantly across multiple [[Availability Zones|availability zones]].
