# SPA Incongruence with Navigation And Route Transitions

In web environment terms, route transitions are side effects caused by users. This is also shared by the mobile environment where one needs to transition from a route to navigate.

It is amusing that Single Page Applications (SPA) do not need to transition to another a route to navigate.

> *In the web, route change is a side-effect from user action, in a SPA, no need to change route to navigate. In native, route change is main action to navigate*
