# Less Known Database Services

- MemoryDB: A database engine used to store data persistently while also being ran in-memory.
- DocumentDB: A database engine used to store documents (nested data structure).
- Keyspaces: A database engine used to store flexible column format data, columns that don’t follow a schema strictly.
- Neptune: A database engine used to store graphs (complex data relations).
- Timestream: A database engine used to store time series data.
- Quantum Ledger Database: A database engine used to store inmutable logs of data, records that depends on previously written records.
