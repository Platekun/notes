# Parameter Groups

A parameter group is a collection of settings values for a RDS database engine. They allow us to add custom specifications to our database configuration.

<aside>
<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> Modifying a parameter group can affect one or more database instances.

</aside>
