# Using Layout Components Exclusively For Layout

Layout components could be a more scalable way of adding spaces between components since we won’t be fighting with margin calculations once the application grows.

> *Components should have zero surrounding white space. And I mean *zero*.
- Space between components is handled exclusively by layout components.*
