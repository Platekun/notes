# What Are Bits?

Binary describes a numbering scheme in which there are only two possible values for each digit: `1` or `0`. 

A digit in binary is called a bit and they are the smallest unit of data in computing. The combination of ones and zeros determines which information is processed by the computer.

```
0 = 0          -> Needs 1 digit (big) to be represented in binary.
1 = 1          -> Needs 1 digit (big) to be represented in binary.
2 = 10         -> Needs 2 digits (bits) to be represented in binary.
3 = 11         -> Needs 4 digits (bits) to be represented in binary.
4 = 100        -> Needs 3 digits (bits) to be represented in binary.
...
255 = 11111111 -> Needs 8 digits (bits) to be represented.
```
