# Waterfall Development Can Be More Efficient Sometimes

Agile is not always the best choice for projects. Waterfall can proof to be a better fit when it comes to problems that won’t evolve over time because they are too well defined. In such cases you can already see the solution and do not need to juggle requirements and priorities.

> *Given a very well defined problem that will not evolve with time;
- and given that there is an obvious solution without competing priorities;
- then the necessary chaos of communication in an Agile team could be less efficient than following an up front plan.*
