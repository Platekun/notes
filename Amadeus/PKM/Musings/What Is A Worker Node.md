# What Is A Worker Node?

In distributed systems, a node can be a hardware device or a software process like a client or a server.

The term "*worker node*” can be seen in different context within distributed systems however there isn't a clear cut definition for it. Within the context of [[What Is A Blockchain|Blockchain]], I will be using the term to refer to a computer or device that completes a specific task within the blockchain, that is a node that provides compute capacity needed by the [[What Is Distributed Consensus|leaderless consensus protocols]] like [[What Is Proof-of-Work|PoW]], [[What Is Proof-of-Stake|PoS]], etc.
