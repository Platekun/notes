# Networking

[[What is EC2|EC2]] instances can have two [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]]: a [[Public IP Addresses|public]] one and a [[Private IP Addresses|private]] one.

- [[What is EC2|EC2]] private [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]]: Used to communicate with other resources inside the [network](https://app.notion.com/p/79477ef005f249c0afff3574478fbc07?pvs=21).
- [[What is EC2|EC2]] public [[Amadeus/PKM/Musings/IP Addresses/What Is An IP Address|IP addresses]]: Used to communicate with a specific instance from the internet. By default they are [[Dynamic IP Addresses|dynamic]], however one can request AWS for a [[Static IP Addresses|static]] one, called “*Elastic*” in AWS context.
