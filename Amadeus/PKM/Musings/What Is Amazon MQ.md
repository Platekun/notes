# What Is Amazon MQ?

[](https://us-east-1.console.aws.amazon.com/amazon-mq/home?region=us-east-1#/)

The Amazon MQ (also known as Message Queue) service is a service provided by [[Amadeus/PKM/Musings/What Is AWS|AWS]] used to create and manage message brokers using Apache Active MQ and RabbitMQ.
