# State Charts For Strict Navigation

State Charts and Finite State Machines make more sense when it comes to controlling transitions which need to be strict. The web is a complete opposite of this with anchor tags. A sentiment shared by [‣](https://app.notion.com/p/771dae544f4d4ee88931e1da30a86f34?pvs=21).

> *Yeah routers are wildly variable as [@ryanflorence](https://twitter.com/ryanflorence) and [@mjackson](https://twitter.com/mjackson) can attest to. Using FSMs/statecharts for them only makes sense if there are strict transitions (such as a wizard).*
