# Internet Gateway

An internet gateway is a [[What Is A VPC|VPC]] component (a combination of hardware and software) that allows communication of the resources inside our [[What Is A VPC|VPC]] and the internet.

If a [[What Is A VPC|VPC]] does not have an internet gateway, its resources cannot be accessed from the internet.
