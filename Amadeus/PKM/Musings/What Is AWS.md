# What Is AWS?

AWS stands for “*Amazon Web Services*”, a subsidiary of [https://amazon.com](https://amazon.com).

AWS is a “*Cloud Computing Service Provider*” *([[What Is Cloud Computing|What Is Cloud Computing?]] ),* a collection of cloud services, used by industry leading companies.
