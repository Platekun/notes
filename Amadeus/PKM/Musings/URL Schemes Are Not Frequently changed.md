# URL Schemes Are Not Frequently changed

For an unknown reason libraries are abstracting away implementation details like the URL scheme however this is not a big issue since those schemes rarely change once implemented.

> *I feel like a lot of routers are built to name routes such that the actual URL string is abstracted away, maybe so you can change it all in one place, but URL schemes change really infrequently cause that’s what they’re for!*
>
