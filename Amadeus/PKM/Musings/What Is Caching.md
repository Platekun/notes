# What Is Caching?

Caching is a technique in systems design that consists in retrieving previously computed data in order to reduce workloads and improve response times for servers and databases.

Caching focuses on storing data generated by the system which is considered ephimeral (short-lived) on a different “*layer*”. Once data is stored in this “*layer*” subsequent requests will be served up faster than retrieving and computing the data from the database. This ephimeral storage “*layer*” is commonly know as a “*cache*” and they are optimized for fast data retrievals.

Caches serve as a central layer which can be accessed by different systems. They are generally used as a different node which can scale independently of the rest of the other nodes in the system.
