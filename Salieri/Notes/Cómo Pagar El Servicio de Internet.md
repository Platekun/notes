# Cómo Pagar El Servicio de Internet

1. Navega a [https://portalpagos.claro.com.co/index.php?view=vistas/personal/claro/newclaro/inicio.php&id_objeto=#no-back-button](https://portalpagos.claro.com.co/index.php?view=vistas/personal/claro/newclaro/inicio.php&id_objeto=#no-back-button).
2. Selecciona "*Pago de Facturas*” como "*Opción de interés*”.
3. Selecciona "*Postpago*”.
4. Escribe "`3114022145`” como "*Número de celular*” o "`04579153`”.
5. Pressiona "*Pagar*”.
6. Llena la información correspondiente.
7. Procede con el pago con el método de pago elegido.
