# Cómo Pagar El Servicio de Electricidad

1. Navega a [https://caribesol.facture.co/Pagar](https://caribesol.facture.co/Pagar).
    1. Escribe “`1075226`” como el “*NIC*”. 
2. Llena la información correspondiente.
3. Acepta los términos y condiciones.
4. Selecciona “*Valor Total*”.
5. Procede con el pago mediante PSE.
