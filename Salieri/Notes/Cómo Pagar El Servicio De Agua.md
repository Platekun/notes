# Cómo Pagar El Servicio De Agua

1. Navega a [https://gp.aaa.com.co/Pago#/List](https://gp.aaa.com.co/Pago#/List).
2. Escribe "`1039488`” como la "*Póliza*”.
3. Presiona "*Pagar*”.
4. Llena la información correspondiente
5. Procede con el pago mediante PSE.

<img src="https://app.notion.com/icons/info-alternate_blue.svg" alt="https://app.notion.com/icons/info-alternate_blue.svg" width="40px" /> The "*Póliza*" number can be found on the receipt.

</aside>
